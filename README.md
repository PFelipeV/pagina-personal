# Página personal · Felipe Vergara

Sitio estático (HTML + CSS, sin frameworks ni JavaScript) orientado a un rol de AI Engineer.

**Sitio publicado:** https://pfelipev.github.io/pagina-personal/

## Archivos

- `index.html`: contenido (hero, sobre mí, proyectos, stack, trayectoria y contacto)
- `styles.css`: diseño responsivo, tema claro en tonos cálidos
- `felipe-vergara.png`: foto de perfil
- `cv-felipe-vergara.pdf`: CV descargable desde el botón "CV"

## Ver en local

Abre `index.html` en el navegador, o sirve la carpeta:

```bash
python -m http.server 5500
```
